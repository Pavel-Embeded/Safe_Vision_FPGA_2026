# 早期定位用视频测试

此文件保留 V3 视频装配初期、只有几何占位图层时的定位测试源码，便于解释旧运行证据的适用范围。它没有最终字符字幕/HUD 的独立字形参考模型，不能验收最终 E01/E04/E05，也没有生产仿真清单引用。

最终入口 `video_v3_sim.json` 已选择带真实字体、完整输出画面和独立混合/缩放参考模型的 `tb_v3_video_final_base` 与 `tb_v3_video_final_hd_fast`。缓存、相关时钟打包、共享物理内存压力、数字字形及 1:1 视窗另有独立显式清单。最终源的证据索引见 `docs/v3/video_validation.json`。
