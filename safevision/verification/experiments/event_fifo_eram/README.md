# 未采纳的事件队列物理 RAM 候选

`rtl/common/v3_event_fifo.v` 是独立候选，未接入 `error_report`、板级顶层或综合清单。候选保持原 8 项事件队列的 FWFT 时序，通过旁路处理首次写入，以及只剩一项时的同拍弹出与压入，避免依赖 RAM 读写冲突行为。

`event_fifo_sim` 使用原 `sync_fifo` 逐拍对照，同时由独立8项队列核对完整44bit事件、满空、反压、指针回卷和复位epoch。最初测试68341次比较零错；修改任何候选、测试或清单后须重新运行。

实际TD 6.2同参数内部模块综合只从84降到67等效LUT，却新增3个RAM9K。此处并未证明整机节省17LUT；内部模块直接作为顶层时的I/O打包和全工程映射并不等同。有限RAM预算下没有据此采用此结构。原始资源报告位于开发运行目录 `work/runs/event_fifo_area`；不把该候选列为发布功能或时序通过。
