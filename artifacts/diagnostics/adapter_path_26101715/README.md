# 26101715：生产适配器交叉路径诊断

当前证据尚不能区分单字写入、掩码、BRAM写缓存、BRAM读缓存、上游传输及CRC路径。首末两个物理读数为零不代表整行都是零；CRC期望值等于全零行的CRC也不是无碰撞的数据证明。未据此修改引脚、放行坏帧或宣称厂商编译器错误。

新探针直接复用未经修改的sdram_app_adapter；保持真实MEM50MHz/外部+8ns、厂商PLL与加密SDRAM控制器。奇数轮经适配器缓慢写、直接读；偶数轮直接写、经适配器FAST/PREFETCH读。写读两轮使用同一种图案，六种图案后循环，默认1200轮，每轮连续1024个字地址。慢写间隔512周期，使48周期超时刷写确实产生单字和全掩码补拍。直接路径使用16拍突发、16周期间隔、DQM=0。读取使用已实测的一拍对齐。切换方向前排空已完成读取及预取，并等待至少32个物理静默周期；逐轮只复位适配器，SDRAM内容不复位。

UART为115200/8N1，固定190字节，首行SVADP26101715。CFG最后一位为位字段：bit0=适配器写，bit1=适配器读，bit2=适配器协议错误。001表示写路径测试，002表示读路径测试；005/006另有协议错误。BAD0保存首次错误轮次、字地址、期望及实际；有错即停止。写/读操作和排空均有超时，不会无限等候而没有报告。LED=8表示本探针通过，3表示数据不符，1/2/4/5分别表示初始化/响应/写排空/读请求错误；超时不会被记为比较通过。

它是临时交叉诊断程序，HDMI无图，不是完整应用的删减交付。完整应用源码及已有位流保留。理想接口模型验证控制、地址、握手、比较和UART协议，不能验证加密IP内部、映射BRAM和真实电气行为；只有新一轮实际串口结果才能收窄实物故障。

模型测试为12轮双向六图案、768个正向字比较；两个方向分别注入一位错误，共960次比较、28项检查。报告570字节与独立预计算文件逐字节相等；故障必须精确记录地址5及一个坏字，并停在注入轮次。还逐拍检查反压期间请求稳定，以及384次慢写均为一个有效字加一个全掩码补拍。
