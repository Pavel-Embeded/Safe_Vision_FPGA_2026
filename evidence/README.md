# 验证证据

当前稳定版本的分层结论见 [BASE 26102301 验收](../docs/releases/BASE_26102301/ACCEPTANCE.md)。[调试目录](../docs/debug/README.md) 按阶段和记录组提供原始入口。

| 目录 | 内容 |
| --- | --- |
| `v3` | 已有仿真、资格、时序与负控执行记录 |
| `board` | 原始板测、后续用户实物反馈和验收更新 |
| `debug_history` | 本次无损收录的本地调试记录、来源路径及 SHA-256 |
| `repository_cleanup_261026` | 去重映射、原始证据 Git 对象清单及整理收据 |
| 其他目录 | 早期仿真、测量、波形、来源和阶段索引 |

原始记录保留生成时的字节和状态。`cold_boot_261025_user_report.json` 表示用户已确认真实掉电重启正常；冻结发布包仍保留 2026-10-23 时尚未执行该测试的状态。补充反馈通过独立记录更新当前结论。

日志、输入身份、正常结束和检查结果共同支持通过结论。工具崩溃、超时、SKIP、文件名中的 PASS 或单独截图均不替代完整验收。
