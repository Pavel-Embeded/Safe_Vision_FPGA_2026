# 候选研究，禁止作为通过版本烧录

本目录保留新方案173个明确的物理构建输入及已完成的研究记录，便于在用户本地项目审阅源码。它没有批准位流，尚未通过全部时序和实板恢复验收，不能覆盖当前已批准BASE。

`native_inputs/`沿用业务逻辑、板级IP、约束、显式源清单和工具层次。HD坐标优化已拆为独立`v3_hd_coord_arith.v`，保持20/21拍坐标以及SAFE消隐对齐。SPI新模式明确启用25MHz和REF下降沿采样；默认模式仍兼容旧12.5MHz。音频使用分区局部指针/计数更新。FAT跳簇判环使用严格32位溢出等价式，未增加时序屏蔽。

早期SPI25BASE实际布线setup=-11.733ns，必须修复。当前最新候选仍在构建，物理时序未通过；全部标记以UNAPPROVED_DO_NOT_PROGRAM.json为准。文档中仿真、布局资源、布线STA和实际板测分别保留边界。
