# 四档轮播的实际板卡串口验证

在已校验下载的BASE26101802上，通过COM6实际设置2、5、10、30秒停留，各观察3次连续自动提交；独立复核12次槽位/generation变化、8个相邻间隔、2965个有效有序回执和14组健康状态。默认32帧Fade另需约0.534秒。原始观察间隔包含串口轮询误差，不把毫秒读回当成精确像素边沿；允许观测误差±250ms，轮询间隙逐项限制450ms。所有缓存F、WAV回退0，列明错误均0。最后读回确认恢复5秒自动轮播。

原始字节为rx.bin，全部收发及时间为trace.jsonl；periods.audit.json为独立审计，不使用测试脚本的通过结论替代原始字节。缺少完成标记、虚报间隔和损坏校验和三种反例均被审计器拒绝。运行python -B verify_periods.py可离线校验位流/证据SHA并在独立临时目录重新审计；不会连接串口或覆盖原始记录。
