# SDRAM 64字读诊断（尚未烧录）

这是单独诊断，不是完整BASE/HD应用。它用已实测的50MHz/+8ns配置，直接写入、通过HD的64字读bank读取，六种图案循环两轮，每轮1024字，起始32位字地址4。它检查跨物理行的长读突发，不代表全8MB、长期稳定性或完整HD带宽已经通过。

模型正例核对768个数据字及1386个UART引脚字节，共2154次比较，正常结束零错误；模型明确配置原有的一拍数据/valid合同。厂商加密IP不在模型内。原生布线及重新导入数据库的独立Slow/Fast时序复核均通过；原始报告及精确输入SHA随附。只读重解析报告与原验收对象逐字段一致。

自动审批服务容量不足，临时位流生成进程未启动；未生成此诊断位流，未烧录，不能宣称实际厂商IP长突发已通过。待位流生成和核验后，需先打开COM6并只写SRAM，收集12份SVADP26101918完整报告，逐份核对轮号、图案、1024字计数、零BAD、总计和首错哨兵，然后立即恢复已核验完整BASE并读回健康。禁止写Flash。

独立仿真清单：safevision/build/manifests/adapter_read64_probe_sim.json。
独立原生构建：safevision/tools/run_adapter_read64_probe.py --run-dir <全新ASCII隔离目录>。
这些是诊断入口，不替代完整应用的功能门禁、严格时序和实机验收。
