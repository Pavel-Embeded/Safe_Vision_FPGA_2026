# 2026-10-11 字探针 v3（SV-WPR3）板上采集 —— 原始十六进制
# 采集条件：SRAM 下载 v3 位流（抬头已核对 = SV-WPR3 / ID=26101003），采数期间未断电/未按 CONFIG1
# 解码：
#   SV-WPR3 ST=A FS=7 EC=F3 SD=0 CARD=0 CNT=4 CUR=0 RD=000E1036 PX=4B000 F=0000 SLOT=1 CRC=0 ED=01 R1=00 SQ=4
#   SV-MEM ID=26101003 PH=3 BAD=00135F00 EXP=FFFFFFFF GOT=FFFFFFFF W=FFFFFFFF B=C000
#
# 关键解读（v3 语义）：
#   BAD=00135F00 = 槽基址 0x000A0000 + 0x95F00 = **末块（第 2399 块）基址**
#     —— v3 是反向校验，末块是"第一个被校验的块" ⇒ 与 v2（正序、第 0 块失败）一致：
#        **不是某地址特殊，而是"刚开始读"就坏**。
#   EXP=GOT=W=FFFFFFFF ⇒ 该块第 0/1/63 个读回字**全是全 1**（读回是常数）。
#   B=C000 = {sdr_init_done=1, adapter_init=1, adapter_fault=0, memory_error=0, 通过块数=0}
#     ⇒ 存储子系统自认为一切正常（无 protocol_fault、无 mem_ctrl 超时），却读回全 1。
#   适配器 rdata 复位为 0、rbuf 是寄存器阵列 ⇒ 它产生不了 FFFFFFFF
#     ⇒ 全 1 只能来自 SDRAM 数据总线本身（未驱动→上拉）或那些地址从未被写过。
