# 接口条目模板

| 字段 | 填写内容 |
|---|---|
| 接口 ID / 版本 / 状态 | 例如 IF-AB-01 / v1 / 计划或冻结 |
| 生产者 / 消费者 / 复核人 | A/B/C 与模块文件 |
| 信号逐项 | 名称、方向、位宽、有效电平、单位/编码 |
| 时钟与复位 | 源域、目的域、复位极性、上电/重置后初值 |
| 协议 | valid/ready、toggle/ack、mailbox、FIFO 模式及稳定保持要求 |
| 延迟与吞吐 | 最多/固定拍数、反压、FIFO 深度/水位、数值来源 |
| 异常 | 超时、欠载、满、重试、取消、恢复与旧数据处理 |
| CDC | 信息类型、结构、采样窗口、复位重收敛与约束 |
| 验证 | TB 编号、边界/异常、板级波形、证据路径 |
| 变更记录 | 原版本、差异、受影响模块/测试、双方签收 |

对每条数据流说明 `valid && ready` 才算传输，反压时数据是否必须保持。对固定速率 HDMI 同时写清 `de` 几何有效和 `pixel_valid` 数据有效的区别。
