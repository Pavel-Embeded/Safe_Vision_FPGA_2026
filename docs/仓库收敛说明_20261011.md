只剩最新一版代码、且能用一条命令复现板级验证过的效果**"。历史提交全部保留。

## 三、怎么找回被删的东西

历史**一个提交都没丢**：

```
git bundle create <out>.bundle --all      # 收敛前的全量备份（本机 F:\backup\safevision_all_20261011.bundle）
git log --all --oneline                   # 65+ 个提交仍在
git tag -l "archive/*"                    # 两条保命 tag
```

- `archive/teammate-dqm-7fb219c` —— 队友那条并行线（常驻帧播放 + DQM 读掩码修复）的 tip，
  其**DQM 修复已移植进主干**（见 `sdram_adapter` 的注释），其余部分未并入。
- `archive/card-to-screen-2e97790` —— 2026-10-05 的一个独立提交。

被删文件都在这些提交里，`git checkout <commit> -- <path>` 即可取回。
