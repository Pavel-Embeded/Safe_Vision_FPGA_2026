推送需要 GitHub 凭据，而本机凭据由 `helper-selector` 托管、只能交互式取得，所以请在**你自己的终端**里执行：

```powershell

git fetch origin --prune
git log --oneline origin/main..main | measure -Line        # 只看是否仍是快进

# 2) 推送 main（快进，无需 --force）
git push origin main

# 3) 推送两条保命 tag（保住两个不在 main 历史里的提交）
git push origin archive/teammate-dqm-7fb219c archive/card-to-screen-2e97790

  codex/a-complete-20261006 codex/a-stages11-15-20261004 codex/ab-adapt-20261005 `
```
