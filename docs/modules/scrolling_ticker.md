# 底部中文滚动提示

字幕内容为“安全提示：遇紧急情况，请保持冷静，听从工作人员指挥，并有序撤离。”正常播放和安全画面使用同一条提示。

BASE 的字幕底条位于 x=120 至 631、y=456 至 475，左侧保留运行时间，频谱位于底条上方。正文为白色，底色为黑色，上边缘有一条青色细线。文字从右侧进入，向左移动，完整移出后重新开始。

## 接口与节拍

实现文件为 [v3_scrolling_ticker.v](../../safevision/rtl/video/v3_scrolling_ticker.v)。正式配置选择 `MESSAGE_CHARS=32`、`EXTERNAL_FONT=0`，显示核心选择 `SHARED_TICKER=0`。字库使用独立 RAM，频谱存储器保留原来的系数和显示数据布局。

顶层使用最终显示坐标，提前五列读取字模，再用五拍流水线对齐当前像素。原视频链保持 21 拍延迟。底条与上边线按当前输出坐标计算，可见范围由最终坐标和 DE 裁剪。

位置每两个帧起始脉冲增加一个像素。BASE 配置帧率约为 59.965 Hz，移动速度约为 29.982 像素/秒。32 个字格占 512 列，可见字幕区宽 512 列，一个循环经过 1024 个位置，约 34.153 秒。同一帧中的各行使用同一个位置。

模块使用显示域复位。媒体恢复期间，字幕位置继续推进；全局复位清空位置、计数和像素流水线。

## 字库

正文使用 32 个 16×16 字格，以 14 像素字号绘制。8192 位字模存入一块 RAM9K，按列排列。同步读取输出不加复位，以保持 BRAM 推断。综合网表检查逐位核对数据、校验位与端口字宽。

字体为 Noto Sans SC Medium，采用 SIL Open Font License 1.1。生成入口为 [build_ticker_font.py](../../safevision/tools/build_ticker_font.py)，字体来源、生成参数和文件校验值见 [字库记录](../../safevision/assets/fonts/v3_ticker16.provenance.json)。独立像素参考按行排列，用于检查字模的列地址、方向和流水线位置。

## 串口观察

| 查询正文 | 回值 |
| --- | --- |
| `B:DIAG=101` | 高 20 位为 `544B1`，低 12 位为当前位置，BASE 范围为 0 至 1023 |

位置和 HDMI 状态通过原有握手邮箱传到系统域。每次诊断回复读取稳定快照。主机根据原始回复与采样时刻核对移动速度、回绕和媒体恢复期间的位置。

连续运行检查记录默认参数的写入与回读，并从明确的起点计算运行时长；同时核对原始 ACK、缓存与错误状态，以及自动轮播的 generation 进展。串口记录与实体画面、声音分别验收。

## 验证入口

- `ticker261028`：32 字独立像素参考、完整 BASE 光栅、全部滚动位置、裁剪、消隐、默认 21 拍接口、五列预取及复位。
- `ticker_board261028`：正式顶层的独立字库选择、完整 32 字画面、版本号、诊断边界、跨域快照、packed query 和媒体恢复隔离。
- `resident_owner_equivalence261028`：常驻缓存交接后，逐项对照原播放器公开输出，覆盖任意共享文件上下文与异步复位。
- `shape_factor261028`、`geometry_stages261028`：缩放分支、位宽边界、尺寸锁存，以及几何初始化各级使用的分子和除数。
- `check_shape_space261028.py`、`check_geometry_width261028.py`：独立整数公式遍历宽高组合，检查缩放分支和几何临时值的位宽范围。
- `test_ticker_rom261028.py`：逐位核对综合网表，并检查数据或校验位损坏、错误端口宽度、缺失及重复字库是否被拒绝。

生产清单先读取 `ticker_enable.v`。历史回归继续使用原来的模式清单；生产顶层测试显式启用字幕。库中保留共享字库参数配置，`ticker_shared261028` 用于该配置的兼容性测试，正式配置使用上述独立字库路径。

## 媒体文件服务交接

正式配置启用播放器的 `REGISTERED_RESIDENT_READY`。四张图片装载完成后，常驻模式停留在 `S_READY`，直到媒体复位。外部服务就绪信号取自已有的所有权与间隔寄存器，仍保留原来的两拍交接等待；媒体复位会立即撤销就绪信号。

等价测试逐项比较新旧路径的公开接口。另外两项负向控制分别去掉交接间隔和所有权条件，检查提前开放服务的错误能否被发现。

## 图片几何初始化

等比例缩放的分支判定使用 `3×宽 >= 4×高`，与原来的 `480×宽 >= 640×高` 等价。除法分子保持原值。播放器先保存尺寸，再用两拍完成分支选择和初值装载。50 MHz 参考时钟下，这两拍只在 FLEX 图片装载开始时增加 40 ns。

几何临时值使用 23 位。初始分子取 `480×宽` 与 `640×高` 的较小值，在合法尺寸范围内最大为 7,864,320，小于 2²³。此后的有效减法只会减小余量。原始乘积、行坐标和误差寄存器保留原来的位宽。整数域证明与完整图像像素比较分别记录，像素顺序、颜色、方向、比例和后续逐行接口保持原来的约定。
