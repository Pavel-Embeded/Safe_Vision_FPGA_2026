# 官方赛题一与当前 BASE

用户提供的全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道安路科技选题指南，在 PDF 阅读器第 14 至 15 页列出赛题一。基础要求分四类，扩展功能分五类可选方向，未给出各项固定分值。

| 官方要求 | 当前实现 | 验证与边界 |
| --- | --- | --- |
| 核心功能完整性 | TF/FAT32、BMP、四槽 SDRAM、HDMI、交互及音画提交 | 当前 BASE 原始离线资格和板测保留 |
| 显示稳定性与鲁棒性 | CRC、帧边界切换、预取、欠载监测、SAFE 与恢复 | 已有实板与掉电反馈；长期和跨设备测试另记 |
| 基础音频输出 | WAV/PCM、48 kHz、音量、HDMI、提示音与报警 | 用户确认实际声音；格式范围见架构说明 |
| 系统工程规范性 | 显式依赖、模块契约、分层测试、原始报告、位流指纹与恢复 | 当前入口、调试索引和验证工具可查 |
| 图层叠加与字幕 | 四层合成、状态、菜单、秒级运行时间及底部中文提示 | 字幕按帧移动，像素延迟与主画面一致；实现见模块手册 |
| 图片轮播与转场 | 自动/手动、四档停留周期、32 帧 Fade | 双源渐变和 generation 提交；正常切图实测 |
| 图片自适应缩放 | 任意合法名称与多尺寸 BMP，居中等比例和黑边 | 导入采用最近邻，BASE 显示端为整数缩放坐标 |
| 实时参数与 OSD | 实体八项菜单、亮度、对比度等回显 | 用户确认实体手势和参数变化 |
| 音频可视化 | 512 点 FFT、32 频段、标记和峰值保持 | 实际左声道 PCM；用户确认频谱显示 |

当前 HDMI 输出为 640×480，大尺寸 BMP 在导入时归一化为显示画布。亮度通过实体菜单或串口调整。各功能的测试结果按版本和具体设备组合记录，最终评分由评委依据赛题要求和现场演示判断。

当前证据见 [验收](../releases/BASE_26102301/ACCEPTANCE.md)，实现范围见 [媒体与频谱](../architecture/flexible-media-and-spectrum.md)，模块和契约见 [模块手册](../modules/README.md)。旧需求表中的 B/E 编号沿用当时学习手册，不与本页编号混用。
