# 板卡资料复核与资源优化验收（2026-10-16）

本记录针对 HX4S20C / EG4S20BG256。资料来自用户指定的 `D:\嵌赛FPGA文件`，没有把资料中的操作示例当作执行指令。原始 PDF 不复制到仓库；精确相对路径、字节数和 SHA-256 保存在 `board_reference.json`。

## 容量与验收

器件提供 19600 LUT、19600 DFF、64 个 RAM9K 物理块、29 个 DSP、4 个 PLL。RAM32K 占用四个 RAM9K 物理块，不能将两种资源简单相加。学习手册 V3 附录 F 的余量属于设计目标；2026-10-16 用户明确允许 LUT 超过 80%，要求保留全部功能、在实际容量内完成布局布线、全部时序通过并继续优化。

`resource_policy.json` 将 LUT 硬门槛改为 100%，优化目标仍为 70%；DFF 80%、RAM 85% 保持不变。综合面积通过并不代表打包、放置、布线通过，4900 个 MSlice 等物理限制仍由原生工具检查。所有角的 setup、hold、recovery、removal 以及约束实际命中检查仍为强制条件。历史 80% 检查失败记录保留原判定，不追改成通过。

## 核对结果

- 板卡手册 HDL2410 全文、八张板卡原理图、EG4S20 器件/封装资料及 PLL、IO、DSP 指南用于复核。原理图的 FPGA、电源/配置、GPIO、TF 和 HDMI 页经过渲染核对；BG256 引脚表也逐项对照。
- 晶振为 50MHz，输入球位 R7；输入周期约束 20ns。系统、视频、音频 PLL 保持独立复位与锁定释放；实际生成时钟仍需在布局布线后重新验收。
- HDMI 使用 B 口，即 HDMI2/J6。D0 为 G5/G6，D1 为 F1/F2，D2 为 E1/D1，时钟为 C3/C2；这些是 BANK3 的真差分对。正端显式约束，负端由 TD 差分输出自动占用。DDC SCL/P2、SDA/R2。HPD/J6、CEC/K5 当前没有进入顶层，不能据此声称已覆盖所有显示器热插拔行为。
- 原理图显示四个 VCCO bank 接 3.3V，内核为 1.2V。HDMI DDC 经 TXB0104 电平转换，不能把 HDMI 侧 5V 直接当作 FPGA 输入电压。高速链路电气质量仍需硬件测量。
- TF SPI 使用 SCLK/A14、MOSI/A13、MISO/B14、CS/A12。DAT0 的外部上拉标为 NC，保留内部 MISO 上拉。数据/片选输出保持 8mA。卡时序预算继续采用受支持的数据手册与明确的 PCB 设计余量，不把余量写成实测值。
- 按键低有效：复位 A2、下一张 B2、应急 B1、自动 C1；LED 高有效 A4/A3/C10/B12。CH340 的 FPGA TX 为 D12、RX 为 F12。
- 2M×32 SDRAM 是封装内部资源，共 8MiB，通过专用 IP 连接；工具中的 Sxx 内部 PAD 不是需要人工分配的外部 BGA 球位。不能用用户 IO 表覆盖它。
- 配置按钮 PROGRAM_B/T2 与用户复位 A2 不同。配置页 R101 接 3V3、R102 接 GND，因此 M0/T11=1、M1/N11=0，符合 MSPI。原理图 U39 标为 W25Q16，即 16Mbit；板卡手册有“64M”叙述，下载步骤以原理图器件标识为依据。

独立管脚契约包含 21 个逻辑端口、25 个物理用户 PAD。`check_v3_board_reference.py` 比较实际 ADC、输入时钟约束以及最终 routed IO 表，拒绝 HDMI A/B 混用、缺失/重复 PAD 和差分负端冲突。

## 保留功能的资源优化

1. Alpha 使用精确偏置恒等式，减少动态背景乘 255 的加减逻辑，保持 RGB565 舍入、三级延迟及每拍一像素。独立候选已覆盖全部通道组合、复位和气泡；生产版本仍重新跑完整 BASE/HD 输出帧。
2. WAV 四路不可变描述符放进原有上下文 RAM 的 128..143 地址；0..71 上下文区保持不变。目录端增加有效反压，启动时读取四个描述符字，不减少四路音频或碎片簇链支持。
3. 板级 UART 用 1024×8 ROM 精确匹配全部 35 个命令，无哈希碰撞。通用 `v3_uart_link` 默认保留任意名字的旧解析行为，板顶层显式选用命令目录。检查脚本直接比对所有消费端名字、ROM 字节和输出译码，新增命令漏更新时拒绝构建。
4. GUI 和命令行共用八项 TD 参数，包括 `infer_fsm off`（保留 RTL 状态编码）、`area_prior` 和 ripple64。导出并核对实际 rtl/gate/place/route 参数表；setup/hold 优化保持开启。

旧综合基线 BASE=17634 LUT、HD=18340 LUT；前述三项候选组合为 BASE=16305、HD=17010，分别减少1329、1330 LUT，RAM 50→51。加入通用 UART 兼容分支后的生产树需要重新综合，此处只记录候选实测值，不当作最终资源或时序结论。

## 当前边界

当前工作源码的102个不重复原生顶层全部正常结束通过，包含完整BASE/HD帧、真实SPI联合读图/音频、两项命令目录测试及新增GPIO顶层复验；13项严格功能/音频故障注入正常结束并检出。`evidence/v3/resource_102_20261016` 保存原始日志、输入、源指纹和可移植审计。完整布局布线、全角时序与位流仍待物理收敛，不能由功能回归推出。不存在“没有板卡也保证第一次上板绝无错误”的已证结论：厂商加密 IP、实际卡和显示器、电源/信号完整性及硬件长稳仍需板测。
