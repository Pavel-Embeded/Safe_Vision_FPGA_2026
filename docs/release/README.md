# 可复现构建与发布

候选版本必须附：Git commit/tag、目标板/器件、TD/ModelSim 版本、IP 版本与许可、`build/manifests` 文件表、配置参数、`pin.adc`/`timing.sdc` 哈希、bitstream 哈希、完整仿真/STA/CDC/板级与长稳证据、未解决问题、恢复到上一个版本的方法。

冻结门槛：B01–B04 每项可从需求表追到测试与原始证据；A/B/C 接口版本一致；无未审查的 CDC 或未约束路径；目标模式 WNS/WHS 合格；故障降级和恢复覆盖约定的媒体路径。仅有仿真时发布“开发快照”，不得称比赛最终版。生成文件放 `safevision/build/out/`（Git 忽略）；经审核的最终物料和哈希由提交责任人归档到独立交付包，证据索引记录位置。
