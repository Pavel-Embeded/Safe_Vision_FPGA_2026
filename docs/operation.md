# 使用说明

## TF 卡

使用 FAT32 分区，将至少四张合法 BMP 放在根目录。固件按文件名顺序选择前四张，建议用 `01`、`02`、`03`、`04` 作为名称前缀控制播放顺序，例如：

```text
01_进站指引.bmp
01_进站指引.wav
02_换乘提示.bmp
02_换乘提示.wav
03_安全提示.bmp
04_出口指引.bmp
```

图片支持 24 位、32 位 BI_RGB 无压缩 BMP，以及自上向下、自下向上的行存储。读取模块对单边尺寸设置了 16384 像素上限；文件是否可用还要通过头部、偏移、长度和数据完整性检查。

已完成实板确认的图组包含 480×800、641×479、1280×720、1920×1080。图片按比例进入显示画布，竖图左右留边，宽屏图上下留边。菜单中的 `1:1` 以归一化画布为基准。

WAV 使用 48 kHz、16 位、双声道 PCM。固件优先寻找同名 WAV，随后按播放顺序匹配卡内 WAV；音频回退使用片上提示音。更换卡内素材后复位，让系统重新扫描和装载。

## 按键

| 按键 | 播放状态下的操作 |
| --- | --- |
| KEY1 | 复位当前应用 |
| KEY2 短按 | 下一张；安全或媒体异常状态下请求恢复 |
| KEY3 短按 | 切换自动轮播与手动模式 |
| KEY4 | 请求应急显示 |
| KEY2 与 KEY3 同时长按约 2 秒 | 打开或关闭配置菜单 |

进入菜单后，短按 KEY2 增加，短按 KEY3 减少；长按 KEY2 约 1 秒切换字段，长按 KEY3 约 1 秒退出。组合键松开后再执行下一次操作。

板上的 CONFIG1 会重新加载 Flash 配置，使用 SRAM 临时程序时，按下它会回到 Flash 中保存的版本。

## 菜单

| 字段 | 作用与默认值 |
| --- | --- |
| BRIGHTNESS | 调节画面亮度，默认 80%；按键步进 5% |
| CONTRAST | 调节明暗差，128 为基准；按键步进 8 |
| SCALER | 选择 NEAREST 或 BILINEAR，默认 NEAREST |
| SCALE | 选择归一化画布的 1:1、适配、1/2 或 1/4 显示比例 |
| FADE | 控制转场渐变，默认开启，持续 32 帧 |
| VOLUME | 音量 0 到 100，默认 70；0 为静音 |
| PERIOD | 自动轮播间隔，可选 2、5、10、30 秒，默认 5 秒 |
| OSD ALPHA | 调节叠加信息的不透明度，默认 160；数值越大越实 |

左下角 `UP` 每秒递增，表示本次启动后的运行时间。右下角频谱取自音频数据，显示不同频段的能量分布。顶部 HUD 提供播放槽、缓存、播放模式和错误状态，便于现场核查。

## 串口

使用板载 Type-C 数据口，参数为 115200、8N1，无硬件流控。JTAG USB-B 用于下载，串口工具使用 Windows 实际识别的 COM 号。

只读监视示例：

```powershell
powershell -NoProfile -File safevision/tools/host/monitor_readonly.ps1 -Port COM6 -ExpectedId 0x26102801 -DurationSeconds 60 -OutDir D:/sv_runs/serial_monitor
```

该工具记录状态和串口原始数据。`exercise_ticker261028.ps1` 用于自动操作与配置回归，会发送控制命令，运行期间应避免同时按键。

## Flash 启动与恢复

成品固件归档为 `BASE_26102801_FLASH`，包含下载、校验和恢复所需文件。Flash 写入成功后，断开 Type-C、JTAG USB-B 和外部电源，确认指示灯熄灭，等待至少 10 秒再上电，核对图片、声音、字幕、计时与频谱。

`26102801` 已完成真实断电重启，并保存了重启后的串口记录。更换位流或硬件连接后，按同样步骤验收。
