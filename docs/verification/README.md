# 验证策略与联调顺序

当前 BASE 的验证包括独立参考模型、单元与子系统、原生综合和布局布线、串口采集，以及用户实物观察。325 个独立正向 top 和 278 项语义负向控制保存在资格归档；Slow/Fast 的 setup、hold、recovery 和 removal 均从原始报告重放。

联调记录沿用 I0 至 I10 的顺序：独立链路、彩条、固定帧、像素与换帧、SD 数据、FAT 枚举、文件流、BMP 显示、OSD、应急恢复及 HDMI 音频。每级保留对应提交、输入、判据、原始证据和回退点。

本次安装保存 40 组配置、8 组缩放、4 档周期、100 次换图、10 次恢复和至少 60 秒连续观察的原始发送与接收字节。用户确认完全断电重接后图片、声音、字幕、计时和频谱正常，后续只读串口确认当前固件和健康状态。按用户于 2026-10-29 的要求，两小时长测从本次安装条件中取消，中断记录按原结果保留。

完整复查入口是 `safevision/tools/verify_ticker_flash_delivery261029.py`。它核对交付清单、批准输入、功能和时序、串口、Flash 安装及实物反馈，并在冻结的 BASE 26102301 中执行原有五项检查。原两小时审核工具继续保留，短采集不能通过该入口。模块测试入口见 [模块手册](../modules/README.md)，早期测试分层见 [测试矩阵](test_matrix.md)。
