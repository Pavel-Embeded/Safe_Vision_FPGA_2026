# SDRAM 非对齐突发修复（26101729）

## 故障证据与修正

完整23程序的 TF 首行 CRC 仍失败，不能交付为硬件通过。单字诊断22通过，但没有覆盖实际媒体写入的混合突发、行倒序和暂停组合。诊断25/26在六种图案的写方向累计23136比较6220错误；读方向23136比较零错误。前四图案地址16读取到地址20的数据，最后两图案首错地址33。26对实际App未屏蔽写命令的数据观察没有报错。

独立四bank列锁存/低两位回卷模型精确复现全部六个错误数量、首错地址和首错值。未对齐起点19的一组命令中，逻辑20会回卷到物理16。该模型是可检验的控制器接口解释，不能冒充厂商加密RTL直接仿真。

隔离诊断28把物理写起点向下对齐四字，将0..3个首补齐字、1..16个真实字、尾补齐字组成4/8/12/16/20拍命令，首尾全屏蔽，真实字保留原字节掩码。同步RAM预读地址扣除首补齐长度，使第一个真实物理拍对应缓冲字0。保持原至少16拍命令间隔、读缓存、超时和完成屏障。

实板28在同样混合/倒序/长短暂停和六图案、双方向下，46272比较零错误，其中192保护字；2772串口字节与独立十二报告完全一致。App每轮3856个未屏蔽命令，无数据观察错误。原始证据在 `evidence/v3/board_uart_20261017/adapter_aligned_26101728_automatic`。

## 生产改动

`sdram_app_adapter.v`采用28已上板验证的写逻辑；未改动厂商IP、SDRAM时钟及SDC。保留全部功能。生产ID改为26101729，避免把23的失败记录误认为本次结果。独立诊断模块保持其原始字节，以保留源码/报告/位流绑定。

`tb_v3_read_alignment.sv`的STRICT写模型增加bank回卷规则；增加四偏移×16长度×16掩码、前后各三个保护字的1024组合，原读吞吐、随机稀疏写、预取取消及复位测试保留。读模型仍为理想地址返回，不能据此证明任意未对齐物理读。

验收必须保留正常结束的旧两拍突发、非对齐写起点和原有语义破坏测试。缺少结束、工具失败、SKIP均不算通过。每个变化依赖的仿真需重跑，其余仅可复用字节完全一致的证据。
