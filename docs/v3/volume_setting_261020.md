# 音量百分比柱、输入能量和HD验收边界

本提交保存开发源码，尚未批准新位流。运行中的BASE仍为已验收BASE_f51bae3；新HD及新增百分比柱必须经过完整功能回归、全部时序、位流构建和实体确认后才交付。未上传GitHub，未写Flash。

## 实体观察和改进目的

用户最初认为竖柱不随音量变化。自动串口把音量固定0并回读后，用户确认右下绿色填充消失、灰框保留；固定100后，用户确认约两格绿色。该结果来自用户观察和独立UART回执，不能冒称机器获取了屏幕图像。板上音量已恢复70。

原柱显示floor(输入能量×音量/100)，所以低能量或恒定幅度音轨可能只有少量稳定填充。它继续保留。新增旁边带VOL字样的蓝色百分比柱，0 至 100音量直接对应0 至 100像素、十段刻度；原柱标VU，继续显示随音乐能量和增益变化的估计。手册要求的音量前1024采样能量横条同样保留。尚未测得实体卡当前能量，不能提前断言音轨幅度恒定。

## 模块和数据路径

SYS域v3_user_controls接收音量；顶层将volume放在99位cfg[67:61]，pre-volume energy放在[54:48]。video_cdc_mailbox在真实垂直消隐边界提交整包。新增v3_volume_setting_column只在frame_start锁存并夹紧0 至 100，独立于能量；原v3_volume_column算法及发布时刻保持。两种模式采用相同模块字节和四像素HUD延迟，没有新增时钟、DSP、RAM或图层。VOL/VU小字使用独立5×7局部位图，保留两端口字形ROM。

连续配置发送时，旧待传包可能占用第一帧，第二帧提交新值，第三帧锁存柱高。新增顶层检查沿实际时钟、真实完整光栅和mailbox核对该边界；没有强制坐标、帧信号或配置寄存器。

新增只读B:DIAG=100，原名称/字段和诊断0 至 15不变。回执值bit13:7为0 至 100输入能量，bit6:0为0 至 100当前音量，高18位为0。该读数来自SYS域，不能代替像素域柱高或实体显示证明。示例命令体为B:DIAG=100，外层仍使用既有XOR协议。
