# 音量柱状显示与HD串口长路径修复

当前结果见`board_acceptance_261019.md`：含音量柱的BASE_f51bae3已完成自动下载及600秒串口监测。下文保留各开发阶段当时的结论；其中“尚未生成新位流”不代表当前状态。HD仍未批准。

本轮保留全部手册功能。手册输入侧1024样本能量统计及原横条不变，新增右下方自下而上的分段音量柱。柱高为输入能量等级乘以音量百分比后的整数百分比估计；音量为0时柱为0，增大音量时柱升高。它不是频谱分析，不声称区分频率或直接测量扬声器声压。

柱采用既有原子配置mailbox中的能量和音量，在每帧第一个垂直消隐像素锁存。7拍串行移位相加、至多100拍减法完成精确除100，不使用乘法器或额外图层/BRAM；在消隐内完成，整个可见区域保持稳定。绿/黄/红区及分段间隔，沿用HUD四拍延迟和Alpha融合；应急SAFE、媒体复位、现有文字和横条保留。BASE/HD通过相同命名的独立v3_volume_column模块装配，验收审计要求两份模块字节一致。生产顶层显式开启VOLUME_COLUMNS；旧独立像素参考保持其原参数，新增测试单独验证新功能。

串口十进制累加原式number*10+digit映射为两个级联DSP。HD新增独立v3_command_parser_catalog实现，先以3个操作数的异或/进位压缩，再使用一次24位加法；模2^24结果、接受边沿、校验、范围和回执均不改变。BASE解析器保持原实现。105份HDL清单中的HD显式替换增至11项，完整物理输入186份；GUI/命令行一致。此前“BASE105份HDL未改变”仅适用于上一轮read64优化，本轮BASE的顶层、显示核心及HUD也因新增音量柱而修改，须重新构建验收。
