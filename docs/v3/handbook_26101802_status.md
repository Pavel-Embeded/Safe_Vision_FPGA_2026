## 这轮关键修正与证据

1. SPI使用明确的25MHz传输档，初始化仍为100kHz；MISO在REF50下降沿采样。保持外部最大18/54ns预算，依据真实生成SCLK边沿核对setup30/5010ns和保守hold10ns；1项正确配置、12项静态篡改拒绝及41项原始报告解析器检查通过。完整25MHz四BMP核对614400个32位字、四WAV24000个PCM正常结束。实卡新版三次恢复最大4108ms，当前软件恢复目标已达5秒；旧26101801的5411ms失败证据保留。
2. FAT判环原先的32位加法再比较形成真实长路径。改成`H!=0xffffffff && H>=T`，严格保持32位溢出语义；7078400次逐拍比较、12800个完整事务及三项语义负控通过。没有屏蔽该真实路径。
3. PCM按槽并行更新指针/计数，保持原握手边沿；生产14位分区回绕核对82500个PCM、2326234拍原实现接口一致。HD坐标单独成模块，20/21拍与原标签完全一致，含异步复位与整帧回绕；5284524次逐拍比较通过。
4. 交付程序统一校验旧`commit`和新`source_commit`字段；实际严格BASE验收及9项字段缺失/冲突/源码篡改控制通过。未改动当时已完成构建的173项硬件输入。

显式综合清单105份HDL，厂商IP位于板级适配层，仿真模型只在对应仿真清单中。完整图像输出核对BASE原有2150400、HD原有6451200、手册BASE3686400、手册HD11059200个像素。厂商加密IP内部没有冒称直接RTL仿真覆盖。

## 物理实现与实板结果

BASE独立清洁构建及Slow/Fast的setup +0.110ns、hold +0.053ns、recovery +3.886ns、removal +0.027ns，验收检查通过。资源LUT17819/19600、DFF13578/19600、RAM9K53/64、DSP23/29、PLL3/4。LUT按用户授权允许超过80%，同时必须完成真实布线和时序。所有原始报告、route.db、工具版本、参数、IP及SHA均在包中。

实板：40组配置540个有效有序回执；100次串口换图1433个回执，另自动提交4次；三次恢复各保留六项配置并全部小于5秒。180秒只读监测18次、31次自动提交，列明CRC/呈现/音视频欠载溢出/UART错误计数全0。该记录不等于24小时稳定性验收。

HD当前仍在隔离工程优化。一次无损16位坐标RAM研究虽然5284524拍和三项负控通过，实际只省2LUT却增加RAM及slice，已拒绝；行缓存五路选择器在独立邻域/缩略图参考中通过并减少65slice，但策略2布线仍未收敛，未纳入本位流。后续策略对照不改频率、I/O预算或真实路径约束；研究结果没有提交绑定时不允许批准位流。

剩余实物验收：HD正式全时序与位流、真实音量/显示效果、第二台HDMI设备兼容、实体应急到画面时延、100次实体按键、1000次真实故障、24小时长稳及更新后Flash断电启动。当前全部手册验收状态仍为false。
