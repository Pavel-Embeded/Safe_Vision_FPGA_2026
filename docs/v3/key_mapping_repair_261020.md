# 实体按键菜单故障修正

用户实测确认26102004的秒计时和PCM波形正常，但KEY2+KEY3不能进入菜单。
复核原始HX4S20开发板手册-HDL版2410第19页：KEY1=A2、KEY2=B2、KEY3=B1、KEY4=C1，均按下为低。
旧v3_board.adc及board_reference.json同时把自动键放到C1、应急键放到B1，二者互相比对无法发现共同错误。
故实体KEY2+KEY3实际触发下一图+应急；正确的菜单输入没有同时成立。

本次把btn_auto改到B1(KEY3)，btn_emergency改到C1(KEY4)。保留全部功能RTL、时钟、复位、长按阈值、图像/音频功能与SDC预算。
检查器另外固定四个实体编号与球位，防止ADC和参考表一起接反仍通过；新的原始布局布线报告还须证明实际封装PAD映射正确。
运行时功能ID仍是26102004：这次只修封装管脚，不改变RTL。准确版本以源码提交和位流SHA-256、下载记录区分。

修正后操作：KEY2下一图、KEY3轮播开关、KEY4应急。KEY2+KEY3同时长按约2秒进入菜单，等菜单显示后松开；短按KEY2/KEY3增/减，长按KEY2约1秒切字段，长按KEY3退出。
顶部BRI和CON显示亮度/对比度数值，菜单打开后画面中部出现参数列表。完成新位流下载后须重新做实体按键验收。
仅SRAM烧录，不写Flash；断电或CONFIG1会重载Flash旧程序。不得把旧ID26101003程序当成本修复。
