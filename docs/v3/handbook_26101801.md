## 对手册的解释

逐页检查用户提供的233页 V3.0。第69页和第215页的“自适应”指硬件图像缩放；未发现要求使用环境光传感器自动调光。第80页要求亮度百分比0 至 100、默认80、步长5；对比度 Q1.7 默认128、菜单范围64 至 255、步长8；音量默认70、步长10；缩放档位0 至 3，默认1:1，帧边界生效。第215页要求参数可读回、复位保持。

实际板上 KEY1 是物理复位，KEY2 切下一图，KEY3 切自动轮播，KEY4 应急。保留这些已验证行为：KEY2+KEY3 同时长按2秒进/出配置菜单，菜单内 KEY2增加、KEY3减少，长按KEY2一秒选择下个字段，长按KEY3一秒退出；按键释放时判定普通动作，避免组合操作漏出一次切图。菜单期间暂停自动轮播计时，应急不受菜单限制。

## UART使用

帧格式仍为 `$<A|B|C>:<NAME>[=<十进制>|?]*HH\r\n`，HH为目标字母至参数最后字符的逐字节XOR，115200/8N1，无流控。不能把下面的命令体直接当作带校验的完整串口帧。

| 命令体 | 含义 |
| --- | --- |
| `C:AUTO=1` / `C:AUTO?` | 开启/读取自动轮播；KEY3也能切换 |
| `C:PERIOD=2/5/10/30` | 四档周期，从本次提交或改变周期后重新计时 |

| `A:SCALESEL=0..3` | 四档几何；旧 `A:SCALE=0/1` 仍映射1:1/适配 |
| `A:SCALER=0/1` | 最近邻/双线性 |
| `C:MENU=0/1`、`C:FIELD=0..7` | 可通过串口进入参数菜单、选择字段，均支持查询 |
