# UART真实关键路径修复与MEM活动编码

前一份完整BASE已完成无冲突布线，并完成独立进程的Slow/Fast STA复核，但最差setup为−0.429ns，路径从UART RX数据位到解析器32位拒绝计数器的使能。因此该版本未验收，未生成交付位流；没有通过放宽约束、伪多周期或屏蔽路径取得通过。

新解析器把复杂的拒绝条件只送入一个pending寄存器，内部base每拍跟随已发布值，公开计数为`min(base+pending, 0xffffffff)`。若旧公开值为C、本拍拒绝事件为E，新公开值仍在原来的时钟边沿变为`min(C+E, MAX)`；连续拒绝、最大值饱和和复位行为一致，查询没有多一拍延迟。源码保留完整33位和的溢出位，避免把饱和计数误改为模32位回绕。

验证使用未修改的旧目录解析器作逐拍参照，另使用原有通用解析器对全部合法命令、未知命令、坏校验、前导零、符号、超时和复位进行独立比较。新增边界测试从0xfffffffd开始，检查饱和、连续错误、500次独立事件日志及异步复位。

内部MEM交易数原来仅用来比较状态是否改变，没有暴露为UART绝对交易数查询。在连续的相关MEM50→SYS100状态采样中，每个MEM边沿最多发生一个活动事件，SYS每10ns采样一次，而源事件间隔至少20ns。用一位翻转token即可保留每次活动变化，不会在两次采样之间发生两次源翻转；原32位内部字段布局保留，上31位为零。所有公开UART查询、缓存、CRC保护和媒体功能保留。消费方若变慢、停顿或改用异步时钟，必须改回有握手的编码，不能沿用此模块。

活动测试在三种固定相位（含重合边沿）中分别比较独立源事件日志与接收脉冲总数，覆盖满速突发、间隔和四个复位时期。对应源tag、SYS状态寄存及观察寄存之间均保留真实setup/hold检查，不增加任何数据路径豁免。

实际综合为16857 LUT、13083 DFF、53 RAM9K。相较上一步，LUT增加34（器件容量的0.174%），DFF减少96；增加的小规模组合逻辑用于保持公开拒绝计数的原周期与饱和语义。目标是同时满足真实时序和物理打包，而不是只看LUT数字。最终BASE/HD布局布线、全部角点时序与实体整机仍须重新验收。
