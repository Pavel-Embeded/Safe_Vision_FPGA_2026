## 行CRC表的进一步无损优化（开发中）

HD现有八份专用实现，新增`rtl/hd/v3_row_integrity.v`。四槽每槽480行的签名表按512行对齐，未使用的空洞行永远不能被合法查询选中；RAM9K仍为8块，整机仍53块。原槽号乘480再加行号改成槽号与行号拼接，CRC算法、同步读写边沿、所有公开输出和保护状态机保持一致。BASE仍使用原文件，105份BASE HDL逐字节未动。
