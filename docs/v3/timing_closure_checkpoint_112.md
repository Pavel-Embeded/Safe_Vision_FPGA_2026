## 本次逻辑变化

1. 板级24项B链查询复用已经通过名称目录校验的7bit命令ID，省去重复的96bit字符串译码。所有名称和ID都与35命令ROM逐项校验。独立保留的旧查询逻辑与当前顶层进行了4096周期、12288次输出比较，完全一致，无新增周期。
2. UART RX只对满足`CLK_HZ>0`、`BAUD>0`且`BAUD<=CLK_HZ/32`的配置收窄相位累加器，并采用恒等式`a+16*BAUD>=CLK_HZ`等价于`a>=CLK_HZ-16*BAUD`。每次更新后`0<=a<CLK_HZ`；不满足这些条件的参数保留原32bit实现。三个不同速率配置逐拍对照原版，公共输出、tick与累加器共1350000次比较一致，没有采样相位变化。
3. 监督器33bit加八阈值使用厂商支持的`use_ripple`进位链属性，保留第33位进位、窗口和事件周期。原来345455次逐拍合同和724608次独立比较仍按源码指纹验收；监督器三项语义负控重新运行。
4. 用户控制用命令名`case`展开互斥写入，目标和范围分别验证。亮度−128..127由高25位全0或全1判断；0..255与0..1分别检查高位全0；音量0..100检查非负高位和7bit上限。对所有32bit二进制输入，这些谓词与原有有符号范围条件等价。旧控制模块保留为独立参考，1000000周期的全部公共输出及四个谓词共5000000次比较零差异。没有新增流水线或协议延迟。

控制测试依次覆盖所有signed16输入值的范围谓词，随后混合32bit随机数、边界值、非法目标/名称、查询/写入、按键、菜单、轮播和复位。完整状态比较按实际测试输入逐拍执行，不宣称穷举2^32值或全部输入序列。破坏符号边界、写错目标寄存器两项负控均正常检出。初版重构未通过旧RTL等价检查的运行保留，不计入本检查点。
