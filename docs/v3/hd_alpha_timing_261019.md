# HD精确融合的时序修正

当前源码最新状态：HD同拍事件优先级预测及按时间戳字节分摊负载已纳入九份专用实现之一，BASE105份HDL逐项SHA保持不变。正式功能门禁`gate16`已通过163项不同正向、116项正常结束语义负控及14项补充契约。对应隔离原生布线实际得到setup+0.017ns、hold+0.027ns，18394 LUT、13348 DFF、53 RAM、27 DSP；但这还不是提交绑定的双模式正式验收，正在清洁目录重建BASE/HD及全部四类时序，之后才能生成新位流。以下保留前序失败与修正证据。

CRC16分组候选95973e3已实际完成HD布线，但最终setup为−1.352ns，不能批准位流。最差路径为Fade第二级到最终像素：14.555ns数据延迟、11层LUT、其中布线10.211ns。另有prepared_sy约−0.045ns和文件LBA约−0.064ns的setup路径。完整原始报告见`evidence/v3/handbook_26101901/native03`；BASE仍全部严格通过。

新候选仅替换HD的`alpha_blend`，所有BASE105份HDL保持不动。三拍接口、每拍一个像素、全部Alpha范围、无效周期输出与异步复位均保持。令原第二级分子x=256H+L，则floor(x/255)=H+[L≥255−H]；将back+H与精确进位存入原第二级，第三拍仅做5/6位增量。没有缩小输出色深、近似除法或增加可见延迟。

独立整数除法核对2621440组；原实现保护副本和独立完整精度像素公式核对1060899拍、1054711个有效像素；穷举6位绿色前后景和8位Alpha，红/蓝5位组合同时全部覆盖，并包含24次异步复位及无效周期。舍入边界、商位序及延迟三个故意破坏均正常结束并被发现。正式HD源码入口的Alpha、整机接口及两份完整帧测试均已重新完成：7帧6451200像素和12帧11059200像素，原始日志见`evidence/v3/handbook_26101901/gate15`。

隔离布局中，组合重排方案18435 LUT/13381 DFF/9663 slice，线长1419015；所选流水重平衡18440/13302/9632，线长1405170。它的Fade实例从188 LUT/94 DFF降为124/54，OSD从190/120降为135/80；整机布局仍会因映射和复制变化，不能用局部减少冒充总LUT减少。最终时序和位流仍须使用新源码独立重建。

当前各模式仍105份HDL，HD专用实现9份、物理构建输入184项。163项不同正向、114项正常结束负控和14项补充契约已全部通过；可独立核对`gate15/acceptance.json`和`portable_audit.json`，复用旧证据均逐项绑定实际相同源码SHA。最新物理构建见`native04`：BASE严格通过，HD布线61轮后冲突从最低167增至620，已停止并保留记录。HD尚未取得最终时序通过，不称为双模式通过，不生成或烧录研究位流。

中断前两份完整帧测试没有结束标记，原30分钟串口仅采集约481秒，均明确记录为未完成。重连后实际串口为旧26101003，已自行用校验过的BASE26101802恢复SRAM；40组配置、8项启动默认和540回执重验通过。Flash未更新，新30分钟只读记录已独立通过：90次观察、1443回执、322次自动提交，列明错误0，相关原始字节和可独立重验工具保存在`evidence/v3/handbook_26101802/monitor1800_261019`。没有上传GitHub。

10月19日继续研究：仅将HD原生进位链阈值32改为16，实际布局/布线资源为18300 LUT、13310 DFF、53 RAM、27 DSP，完成布线后像素域setup为+0.186ns；但系统事件时间戳路径为−1.411ns，另有音频读取、CRC及UART等负裕量，整体仍失败。该研究没有提交绑定，没有批准、生成或烧录位流，也没有改动当前生产参数。原厂文档中的`phys_opt -post_route -effort ultra`在隔离数据库上尝试后异常退出3221225477，归类为工具崩溃，不能计为验证通过；原数据库与已批准BASE不受影响。

板卡另外实际完成2、5、10、30秒四档轮播，各3次连续提交，2965个有序有效回执；相邻间隔分别为[2516,2533]、[5500,5563]、[10621,10480]、[30643,30526]ms，包含32帧Fade和串口采样误差。独立原始字节审计、三项审计器损坏控制及离线重验通过；最后读回确认恢复默认5秒自动轮播。证据见`evidence/v3/handbook_26101802/periods_261019`，不替代实体显示/声音验收。

事件优化令每拍的优先级寄存器保存`priority(next_pending)`，与该拍写入的pending精确一致；四个时间戳字节分别由同拍的本地选择寄存器驱动。没有额外检测周期，没有改变事件优先顺序、原始时间戳或SAFE路径。保护的原实现逐拍核对200788次，另重新核对2048种pending有效状态和整机接口。优先级停止推进、时间戳选择迟一拍、提示事件丢失、原始时间戳清零、告警迟一拍及第10位pending漏判六种破坏均正常结束并被检测。只对确实受影响的3项正向和4项既有负控重建，另加2项新负控；其余证据复用前逐项验证当前源码SHA，包括两份共17510400像素的完整HD帧参考。
