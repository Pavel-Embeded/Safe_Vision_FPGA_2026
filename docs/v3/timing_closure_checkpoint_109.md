此处对应 109 项历史源码检查点，所列时序尚非最终发布结果。后续源码继续优化，见 [112项检查点](timing_closure_checkpoint_112.md)。

当前 109 个不同原生正向测试全部正常结束、零失败；23 个严格负控全部正常结束并检出。证据与当前 RTL、测试台、资产、生成输入的每个 SHA-256 逐一核对，见 `evidence/v3/resource_109_20261016/acceptance.json` 和 `portable_audit.json`。历史 106/105/102 项目录不作为修改后源码的当前验收。

全部功能、所有时钟和 I/O 预算保留。位流发布仍要求功能证据、源码提交、最终两模式物理门禁同时通过；当前没有新的正式位流。

## 精确音频水位比较

原预取判断为 `ring_level + ceil(fifo_words/3) + partial < PREFETCH+128`，其中 `partial` 表示一个三字传输组已有部分字进入 FIFO。对正的剩余空间，严格等价于 `fifo_words + 3*partial <= 3*(PREFETCH+127-ring_level)`，并保留 ring_level 必须小于阈值的资格条件。

新 `v3_audio_prefill_compare` 把除三移出 FIFO 水位到 WAV 状态机的路径。没有改变采样、预取、扇区保留量、握手或周期延迟。范围外参数保留原32bit无符号表达式行为。七种参数下进行了 15,024,128 次真实 RTL 与原数学表达式比较，全部零错；20项受影响的音频测试和6项音频负控重新执行，原始指纹匹配当前源。漏算 partial 和边界比较错一字的两个负控均被检出。

## 相同周期的复位分发

新增 `v3_phy_reset_fanout` 共享首级采样，四个受 preserve 保护的末级副本在原来的第二个 SERIAL 上升沿同时释放。异步断言、停钟时保持复位、重新开钟后释放均与原两级同步器一致；没有添加独立的首级采样或多一拍释放。403项专项检查通过。

`v3_hdmi_phy_wrapper` 按通道连接原厂 wrapper，未用输出悬空并由综合删除。原厂 bit reversal、serializer、DDR 实现源文件及 SHA-256 保留。公开原厂串行器 RTL 在行为 DDR 原语下与原连接比较了400,000次输出位，含100次恢复复位，全部一致。提前释放一个通道、接错一个通道的数据两项负控均正常结束并被检出。

单寄存器位置绑定在 TD 中触发 `SYN-8701/PHY-9005`，失败实验保留。最终候选采用文档支持的固定区域：x29..40、y8..37，包含复位分发与串行器，区域内仍由工具合法打包；没有将单 LUT 强制到不兼容物理模型。GUI/CLI 使用相同额外 ADC 和保留层次属性。
